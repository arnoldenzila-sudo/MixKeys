# Contributing to MixKeys

Obrigado pelo interesse em contribuir para o MixKeys.

## Como contribuir

- Reporte erros através das Issues.
- Sugira novas funcionalidades.
- Envie melhorias para o mapeamento de teclado.
- Mantenha o código limpo e bem documentado.

## Regras

- Respeite a estrutura do projeto.
- Teste as alterações antes de enviar.
- Descreva claramente cada alteração.

Obrigado por ajudar a melhorar o MixKeys!
