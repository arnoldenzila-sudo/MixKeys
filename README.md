# Keyboard Performance for Mixxx

Transforme qualquer teclado num poderoso controlador para o Mixxx.

## Sobre o projeto

O MixKeys é um sistema de mapeamento de teclado para o Mixxx, desenvolvido para proporcionar performances rápidas, precisas e intuitivas, inspirado na agilidade do VirtualDJ.

## Estado do projeto

🚧 Em desenvolvimento (Versão 1.1.0)

## Funcionalidades

- Mapeamento avançado de teclado
- Perfis de utilização
- Compatibilidade com Mixxx
- Projeto Open Source
